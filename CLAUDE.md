# Kynova: working rules

## Model

All work runs on Opus 5.5. (Until 2026-11-12, work was split across Sonnet, Fable and Opus; the user replaced that with Opus for everything.)

## How work runs

1. Work is split into groups. Groups run in the order of the status table; none is skipped.
2. Before a group starts, name it.
3. Inside a group, finish all the code first. A typecheck is allowed. Tests, browser runs and screenshots belong to a separate testing group.
4. When a group ends, report: what was done, what is untested, and the next group.
